# Fonts

All fonts are self-hosted; the page makes no third-party font request.

- **Schibsted Grotesk** — the site's display and interface face. WOFF2 Latin and
  Latin-ext subsets from Google Fonts, SIL Open Font License 1.1:
  https://fonts.google.com/specimen/Schibsted+Grotesk
- **Inter** — the actual typeface used by the Loquara desktop app. The app's
  `InterVariable.woff2` is copied into the site so the interface preview matches
  the real window instead of approximating it with another sans. SIL Open Font
  License 1.1: https://rsms.me/inter/
