# Fonts

Self-hosted WOFF2 subsets from Google Fonts, both under the SIL Open Font License 1.1:

- **Archivo** — https://fonts.google.com/specimen/Archivo
- **Source Serif 4** — https://fonts.google.com/specimen/Source+Serif+4

The files were downloaded from `fonts.gstatic.com` with the Google Fonts CSS API and are served locally so the site makes no third-party font request.
